# Shuffle Local
Runs Pokémon Shuffle on Mobile by locally importing data instead of online and a local save.

# Installation Guide
Simply install the APK. It is signed differently, thus it can be installed alongside the official Pokémon Shuffle.

# Features (Not finished yet)
| Feature Name  | Description   | Implemented?  |
| ------------- |:-------------| :-----:|
| Infinite Hearts      | Self Explanatory | Yes! |
| Offline      | Play the game offline without a 3DS or emulating.      |   No |
| Launcher | Choose what features to turn on/off |  No |
| Built-In Modding | Import mods made by the community (skin mods, new content mods)  |  No |

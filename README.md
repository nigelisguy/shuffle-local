# Shuffle Local
Runs Pokémon Shuffle on Mobile by locally importing data instead of online and a local save.

# Installation Guide
Simply install the APK. It is signed differently, thus it can be installed alongside the official Pokémon Shuffle.

# How it works
The game has all assets and data installed. Patches are made in order to overwrite the data locally, instead of grabbing it from online. This allows for modding, offline functionality without a 3DS/3DS Emulator, and most importantly preserve the game. The servers for the 3DS version has shut down on 31 March 2023, and the same may follow suit for the mobile version
